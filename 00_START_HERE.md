## 🎓 How It Works

```
1. USER REGISTERS
   └─ Email + password + info

2. SYSTEM CREATES VERIFICATION
   └─ Generates 64-char token
   └─ Sets 24-hour expiry
   └─ Sends verification email

3. USER VERIFIES EMAIL
   └─ Clicks link in email
   └─ System validates token
   └─ Marks email as confirmed

4. USER LOGS IN
   └─ Can now access account
   └─ After admin approval
```
